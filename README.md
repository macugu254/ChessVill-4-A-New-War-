# chessVill-4 War Edition (own site)
Upload these files to a new GitHub repo, all in the same folder:
package.json, package-lock.json, server.js, game.js, engine.js, war4.html
On Render: New > Web Service > this repo. Build command: npm install   Start command: npm start
The game opens at the site's home page (also at /war). Health check: /healthz
The Race editions are not part of this package. Leave them on their existing Render site.
